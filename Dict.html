全局設定套用於所有默書；個別默書表可喺編輯頁微調覆蓋。

已連接試算表 ID
試算表格式說明

試算表有兩個分頁，基本 4 欄＋可選 ID 欄：

Project｜Type｜Details｜Date｜ID
第一課｜詞語｜學校｜老師｜同學｜2026-10-12｜C01
第一課｜句子｜我喜歡上學。｜2026-10-19｜C02
  • Project：默書表名稱（允許重複）
  • Type：類型（詞語／句子／文章 或 words/sentences/paragraphs）
  • Details：默書內容，用 ｜（全形豎線）分隔每一項
  • Date：默書日期（可選；支援 2026-10-12、12/10/2026、10月12日）
  • ID：唯一識別碼——中文用 C01、C02…，英文用 E01、E02…；App 手動新增會自動分配同規範嘅 ID，絕不重複。同名表請務必填 ID

試算表須共用為「知道連結的任何人」都可檢視。

再次匯入會以試算表為準（按 ID 配對覆蓋，唔會合併同名表）。
